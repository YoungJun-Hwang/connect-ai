# 달빛사주

생년월일과 출생시간으로 **개인 사주를 실제 계산하는** 한국어 웹앱입니다.
React·TypeScript·Vite로 구성했으며, Connect AI 저장소의 `saju-website/`
폴더에서 독립적으로 실행할 수 있습니다.

## PC에서 바로 사용하기

[`dalbit-saju-preview.html`](https://github.com/YoungJun-Hwang/connect-ai/blob/codex/dalbit-saju/downloads/dalbit-saju-preview.html)을 GitHub의
**Download raw file** 버튼으로 저장한 뒤 Chrome 또는 Edge로 엽니다.
생일과 출생시간을 입력하면 설치 없이 사주를 계산할 수 있습니다.
휴대폰 화면 크기를 보려면 브라우저 개발자 도구의 기기 모드를 사용합니다.

수정할 수 있는 소스는
[`dalbit-saju-source.zip`](https://github.com/YoungJun-Hwang/connect-ai/blob/codex/dalbit-saju/downloads/dalbit-saju-source.zip)에 있습니다.
압축을 풀면 `dalbit-saju/` 폴더가 생성됩니다.

## 실행

검증한 런타임은 Node.js 24입니다. API 키나 외부 계산 서버는 필요하지 않습니다.

```bash
git clone --branch codex/dalbit-saju https://github.com/YoungJun-Hwang/connect-ai.git
cd connect-ai/saju-website
npm ci
npm run test:saju
npm run build
npm run dev
```

ZIP으로 받은 경우 `dalbit-saju/` 폴더에서 `npm ci`부터 실행합니다.
개발 서버가 표시하는 Local 주소를 PC 브라우저에서 엽니다.

`내 사주 알아보기` → 주제 선택 → 생일 입력 → `내 사주 계산하기` 순서로
사용합니다. 주제마다 같은 원국을 계산하고, 해당 주제의 참고 설명을 제공합니다.
입력한 이름은 결과 제목에만 쓰이며 원국 계산에 영향을 주지 않습니다.

배포용 결과는 `dist/`에 생성됩니다. 정적 웹 호스팅에 이 폴더를 올리면
사용할 수 있으며, 서버의 인증 정보나 데이터베이스는 필요하지 않습니다.
공개 웹사이트 배포는 별도로 진행해야 합니다.

빌드 후 `npm run export:html`을 실행하면 JS·CSS·화면에 필요한 글꼴을
포함한 `dist/standalone.html`도 생성됩니다. 파일로 받을 수 있는 환경에서
PC 브라우저로 열어 계산할 때 사용할 수 있습니다.

## 제공하는 계산

- 1900년부터 한국 표준시 오늘까지의 양력·한국 음력 생일과 윤달 입력
- 입춘을 기준으로 한 연주, 12절을 기준으로 한 월주, 일주·시주 계산
- 자정 또는 23시 중 일주가 바뀌는 기준 선택
- 한글·한자로 표시하는 사주 원국, 일간, 천간 십성
- 확정된 천간·지지의 기본 오행 개수와 음양 분포
- 올해 입춘 이후 연간지와 일간의 관계
- 계산된 일간·오행·십성에 연결한 전통 명리의 참고 풀이
- 실제 계산 결과와 계산 기준을 담은 텍스트 내려받기
- 입력 정보의 선택적 브라우저 저장·불러오기·삭제

출생시간이 없으면 시주를 만들어 채우지 않습니다. 절기가 바뀌는 날의
연주·월주는 시간에 따라 달라질 수 있어 가능한 값을 함께 표시하며,
확정하지 못한 기둥은 오행·음양 집계에서 제외합니다.

## 계산 기준과 범위

음력 변환에는 한국 음력 표를 제공하는 `korean-lunar-calendar@0.4.0`을
사용합니다. 한국과 중국 음력이 달라지는 날짜를 중국 음력으로 대신
계산하지 않습니다. 절기와 일간지에는 `lunar-typescript@1.8.6`을 사용합니다.
라이브러리의 중국 표준시(UTC+8) 절기 시각을 한국 표준시(UTC+9)로 맞추며,
일주·시주는 선택한 한국 날짜 경계를 별도로 적용합니다.

절기 시각은 라이브러리의 천문 모델에 따른 값입니다. 공식 한국천문연구원
연표와 초 단위 정확도를 대조했다고 보증하지 않습니다. 입력은 분 단위이며,
절입에 아주 가까운 출생은 세부 시각과 계산 방식에 따라 결과가 달라질 수
있습니다. 결과 화면에서 적용한 기준과 불확실성을 확인할 수 있습니다.

UTC+9를 고정 적용합니다. 1954–1961년의 한국 UTC+8:30 표준시와 과거
서머타임, 출생지 경도·진태양시 보정은 적용하지 않습니다. 해외 출생이나
과거 시각 보정이 필요한 출생은 별도 만세력과 함께 확인해야 합니다.

오행은 확정된 각 천간과 지지의 기본 속성을 한 번씩 센 값입니다.
지장간·계절 가중치와 합충을 포함하는 세력 분석이 아니며, 개수만으로
신강·신약이나 용신을 판단하지 않습니다. 대운·월운, 두 사람의 궁합,
미래 사건 예측, 전문가 상담·접수·결제는 제공하지 않습니다.

## 개인정보

계산은 브라우저 안에서 이루어집니다. 입력을 서버로 보내지 않으며,
`입력 정보를 이 브라우저에 저장할게요`를 선택했을 때만 로컬 저장소를
사용합니다. 체크하지 않으면 새 입력을 저장하지 않습니다. 저장한 정보는
계산 창의 삭제 버튼으로 지울 수 있고, 결과 파일은 직접 내려받을 수 있습니다.

## 검증

`npm run test:saju`는 알려진 일간지, 한국 음력 윤달, 존재하지 않는 날짜,
입춘·월 절입의 한국 시각 경계, 23시·자정의 일주와 시주, 시간 미상의
불확실성, 미래 날짜 및 한국 기준 연도를 검증합니다. 테스트와 함께
TypeScript 검사·프로덕션 빌드를 실행할 수 있습니다. 제작 환경에서는
실제 Chromium의 입력→계산→결과 흐름, 다운로드, 저장·삭제와 모바일
레이아웃도 확인했습니다.

번들로 제공합니다. 참고 주소는 `https://saju-unni.com/`이며, 현재
