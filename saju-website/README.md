# 달빛사주

한국 생년월일과 출생시간을 사용하는 사주 리포트 웹앱입니다.
React·TypeScript·Vite 화면과 Node.js 24 주문 서버로 구성하며,
Connect AI 확장과 별개인 `saju-website/` 폴더에서 실행합니다.

현재는 **유료 상품과 주문·승인 검증 구조를 구현한 판매 준비 단계**입니다.
실제 Wix·네이버페이 가맹점은 연결하지 않았습니다. 기본 실행에서 결제는
비활성 상태이며 전체 개인 리포트를 발급하지 않습니다.

## PC에서 실행

[`프로젝트 ZIP`](https://github.com/YoungJun-Hwang/connect-ai/blob/codex/dalbit-saju/downloads/dalbit-saju-source.zip)을
받아 압축을 풀고 `dalbit-saju/` 폴더에서 실행합니다.

```bash
npm ci
npm run dev
```

터미널의 Local 주소를 브라우저에서 엽니다. Windows에서는 `package.json`이
있는 폴더 주소창에 `cmd`를 입력해 명령창을 열 수 있습니다. Git으로 받은 경우
`codex/dalbit-saju` 브랜치의 `connect-ai/saju-website/`에서 실행합니다.

설치 없이 화면을 보려면
[`HTML 파일`](https://github.com/YoungJun-Hwang/connect-ai/blob/codex/dalbit-saju/downloads/dalbit-saju-preview.html)의
**Download raw file** 버튼으로 저장한 뒤 Chrome 또는 Edge에서 엽니다.
이 파일은 상품·입력·주문 확인 화면용이며 유료 결과나 실제 결제를 제공하지 않습니다.

## 10종 상품

사용자와 합의한 임시 1회 구매 가격이며 자동 갱신 구독이 아닙니다.

| 리포트           |     가격 |
| ---------------- | -------: |
| 인생 사주        | 12,900원 |
| 연애와 관계      |  9,900원 |
| 올해의 흐름      |  9,900원 |
| 일과 재물        | 12,900원 |
| 직업과 이직      |  9,900원 |
| 재물과 소비      |  9,900원 |
| 학업과 성장      |  6,900원 |
| 가족과 관계      |  9,900원 |
| 전환기의 선택    |  9,900원 |
| 마음과 생활 리듬 |  6,900원 |

공통 원국·일간·오행·천간 십성에 주제별 해석 근거, 서로 다른 7일 실천 계획,
자기점검 질문 3개를 연결합니다. 7일은 기록 순서이며 길일이나 운의 시기 계산이
아닙니다. 연애·가족은 개인 명식을 읽는 주제로 두 사람의 궁합을 포함하지 않습니다.

## 주문 서버와 결제

주제 → 생일 → 가격·구성 → 결제창 → 서버 승인 확인 → 리포트 순서입니다.
서버가 가격과 소유권, 승인 금액·통화·주문·거래 ID를 확인합니다.
미지급·취소·환불·검증 실패에는 리포트를 제공하지 않습니다.

```bash
npm run build
npm start
```

기본 서버 포트는 8787이며 가맹점 미연결 상태입니다. 검증된 PG 어댑터와
운영 설정을 연결한 뒤에만 `.env.local`에 `VITE_CHECKOUT_API_URL=/api`를
설정하고 다시 빌드합니다. 환경변수나 키만 추가한다고 결제가 활성화되지 않습니다.
인증키를 프런트엔드의 `VITE_` 변수에 넣지 마세요.

[결제 검토와 보완 계획](docs/PAYMENTS_KO.md),
[서버 계약과 운영 한계](server/README.md)를 확인하세요.
정적 호스팅에는 주문 서버가 실행되지 않으며 Wix의 사이트 삽입만으로 결제가 연결되지 않습니다.

## 계산·개인정보·검증

한국 음력은 `korean-lunar-calendar@0.4.0`, 절기는 `lunar-typescript@1.8.6`을
사용합니다. 1900년부터 한국 표준시 오늘까지, UTC+9, 일주 경계 0시/23시를
지원합니다. 시간 미상에는 시주를 만들지 않고 절입 경계의 불확실성을 표시합니다.
미확정 기둥은 오행·음양과 주제 해석 근거에서 제외합니다.

공식 천문연표와 초 단위 대조는 하지 않았습니다. 과거 표준시·서머타임·출생지
경도·진태양시·해외 시각을 보정하지 않습니다. 오행은 보이는 글자의 기본 개수입니다.
지장간·계절 강약·신강신약·용신·대운·월운 종합 풀이, 전문가 상담, 의학 진단,
투자 수익·미래 사건 예측은 포함하지 않습니다.

주문 전에는 브라우저에서 날짜를 검증하고 동의한 경우에만 생일을 저장합니다.
구매를 진행하면 이름·출생 정보·주제가 주문 서버로 전달됩니다. PG가 결제를
처리하고 카드 정보는 앱에서 받지 않습니다. 주문 ID만 세션 저장소에 남기고
서버 소유권 쿠키로 확인합니다. 다른 기기 복구·정식 보유 및 삭제 정책은 운영 전 보완해야 합니다.

```bash
npm test
npm run build
npm run export:html
```

47개 테스트는 만세력 19개, 주제 10개, 주문·결제 경계 18개입니다.
결제 테스트는 테스트 파일의 어댑터로 진행하며 실제 돈을 받지 않습니다.
제작 환경에서 Chromium의 모바일·PC 화면과 테스트 승인·다운로드·환불 차단도
확인했습니다. 실제 Wix·네이버페이 승인·정산·환불은 검증하지 않았습니다.

`dist/`는 화면 빌드, `dist/standalone.html`은 독립 화면 파일입니다.
글꼴·패키지 라이선스는 `public/THIRD_PARTY_NOTICES.txt`에 있습니다.
