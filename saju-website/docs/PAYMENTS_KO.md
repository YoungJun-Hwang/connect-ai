# 한국 사업자 결제 검토와 보완 계획

검토 기준: 2026년 10월 11일, 한국 사업자, KRW 1회 사주 리포트 판매.
실제 PG 가맹점 계정·상품 심사 결과·인증키는 제공되지 않았습니다.

## 확인 결과

Wix·네이버페이 공식 문서는 도메인 제한으로
`Tunnel connection failed: 403 Forbidden`을 반환했습니다.
다른 공식 경로와 추가 읽기 권한에서도 같은 오류가 났습니다.
원서버 본문을 받지 못해 한국 지원 국가·PG 목록·상품 허용 조건을 확정하거나
문서를 읽은 것처럼 인용하지 않습니다. 현재 결과는 **지원 여부 미확정**입니다.

기존 도메인은 유지하고 Wix·네이버 문서와 참고 사이트의 접근 허용 변경을
클라우드 환경 초안에 저장했습니다. 초안 저장만으로 실행 환경에 적용되지 않습니다.
환경 설정에서 검토·저장하고 환경을 게시한 뒤 공식 문서를 다시 확인해야 합니다.

## Wix에서 확인할 순서

1. 사업장 국가 한국·판매 통화 KRW로 설정하고 결제 수단 연결 화면의 PG를 확인합니다.
2. Wix Payments 자체 서비스와 외부 PG 연결을 구분하고, 한국 사업자·KRW·
   디지털 사주 리포트 판매를 해당 결제사가 승인하는지 확인합니다.
3. PG의 네이버페이 지원과 Wix에서 해당 수단을 제공하는지를 각각 확인합니다.
   PG의 지원만으로 Wix 연동을 보장하지 않습니다.
4. 외부 React 앱의 상품·주문·구매 권한을 공식 API나 플러그인으로 연결할 수
   있는지 확인합니다. 사이트 삽입은 결제 연동과 별개입니다.
5. 승인·취소·환불·중복 통지와 다른 기기의 구매 복구를 테스트합니다.

확인할 공식 경로(이번 환경에서는 본문 미열람):

- [국가별 결제 제공자](https://support.wix.com/en/article/available-payment-providers-in-your-country)
- [Wix Payments 지원 국가](https://support.wix.com/en/article/wix-payments-supported-countries)
- [Wix 개발 문서](https://dev.wix.com/docs/)

## 네이버페이 대안

Wix에서 필요한 국내 결제를 제공하지 않는 경우 다음 경로를 검토합니다.

1. 네이버페이에 사주 디지털 리포트·무형 콘텐츠 판매가 가능한지와 필요 서류를 확인합니다.
2. 계약이 주문형인지 결제형인지, 자체 사이트용 API를 제공받는지 확인합니다.
3. 가맹점 승인 후 공식 테스트 환경과 인증 정보를 서버에 설정합니다.
4. 서버 가격으로 주문을 생성하고 공식 절차로 승인을 검증한 뒤 리포트를 제공합니다.
5. 취소·환불과 구매 복구를 구현하고 실제 PG 테스트를 진행합니다.

- [네이버페이 개발센터](https://developers.pay.naver.com/)
- [네이버페이 가맹점센터](https://admin.pay.naver.com/)

현재는 서버 어댑터 계약까지 구현했습니다. 가입 자격·사주 상품 허용·실제 API
연동은 미확인입니다. 인증키를 브라우저에 넣거나 완료 주소로 권한을 주지 않습니다.

## 차별화와 보완

구현: 가격·제공 범위를 먼저 보여주는 10종 상품, 실제 글자에 연결된 해석 근거,
시간 미상·절입 경계의 불확실성, 주제별 7일 실천 계획과 질문 3개,
선택적 생일 저장·삭제와 승인 결과 다운로드.

사주언니도 같은 네트워크 제한으로 읽지 못했습니다. 위 항목은 우리 서비스의
방향이며 타사에 없는 기능이라고 판정한 비교 결과는 아닙니다.

우선 보완할 사항:

1. 회원 또는 검증된 이메일을 통한 구매 내역과 다른 기기 재열람.
2. 사업자·문의 정보, 제공 시점, 실제 상품에 맞는 취소·환불 조건,
   개인정보 보유·삭제 정책.
3. 지장간·계절 강약·대운 등 풀이의 깊이. 명리 규칙과 검증 기준을 먼저 정해야 합니다.
4. 두 사람의 원국 비교 리포트와 전문가 검토를 별도 상품으로 검토.
   현재 상품에 궁합·전문가 상담이 포함된 것은 아닙니다.
5. 단일 서버 SQLite에서 운영용 영구 저장소·접근 통제·백업·삭제 절차로 보완.

가맹점 연동·상품 심사·운영 조건을 확인하기 전에는 판매 준비 상태를 유지합니다.
