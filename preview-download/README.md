# Connect AI 브라우저 미리보기

[미리보기 ZIP 다운로드](./connect-ai-browser-preview.zip?raw=true)

1. ZIP을 다운로드하고 압축을 풉니다.
2. `connect-ai-browser-preview/index.html`을 PC의 Chrome 또는 Edge에서 엽니다.

실제 VS Code 확장의 독립된 초기 프로필에서 내보낸 화면입니다. 에이전트 카드, 전체/활성/채용 대기 필터와 상세창을 확인할 수 있습니다. 이미지와 스타일이 HTML 안에 포함되어 있어 설치나 외부 서버 연결이 필요하지 않습니다.

AI 실행, 설정 저장, 도구 실행, 외부 API 연결은 이 미리보기에 포함되지 않습니다. 해당 기능은 VS Code 확장에서 사용할 수 있습니다.

브라우저에서 HTML 내용을 로드하여 카드 10개, 필터, 상세창, 실행 불가 안내를 검사했고 외부 네트워크 요청과 JavaScript 오류는 0건이었습니다. 클라우드 관리 브라우저의 `file://` 직접 이동은 관리자 정책으로 차단되어 HTML 내용 로딩 방식으로 검사했습니다.

이 브랜치는 다운로드용 ZIP과 안내 파일만 추가하며 기존 애플리케이션 파일은 변경하지 않습니다.
