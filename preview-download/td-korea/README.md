## 포함된 내용

- POS 이미지가 적용된 메인 화면
- PC·태블릿·모바일 화면 배치와 모바일 메뉴
- 고정비 점검, 지원금·지원사업 확인, 서비스 상세 안내
- 리포트 예시, 운영 원칙, 준비자료, 자주 묻는 질문
- 기존 경영진단 페이지 연결

## 현재 운영 범위

상담 접수처와 회사정보는 확정 전입니다. 고객정보를 서버로 전송하는 폼은 없습니다. 기존 경영진단은 입력값에 따른 기초 점검이며 AI 분석이나 미수령 지원금 자동조회 기능이 아닙니다. 진단 페이지는 별도 접근 권한의 영향을 받습니다.

기존 chatgpt.site 주소의 배포본과 아임웹 편집 화면은 이번 GitHub 변경으로 갱신되지 않습니다.

## 확인 범위

섹션 링크, 중복 ID, H1, 이미지 포함 여부, JavaScript 문법을 확인했습니다. 현재 실행 도구가 없어 실제 브라우저의 렌더링과 모바일 터치 동작은 미검증입니다.
